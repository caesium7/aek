# aekfc
A lightweight Python library to check AEK Athens F.C.'s next scheduled match.
# How to - version 0.4.x
pip install aekfc
import aek
Try out aek.next(), aek.rank(), aek.copyright(), or aek.forza() for a hidden Easter egg.
