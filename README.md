# AEK python module
Creating a python module for AEK Athens F.C.'s fixtures.

# How to

Type import aek into python to import the module.

# **Description**

A lightweight, zero-dependency Python library and CLI tool to check AEK Athens F.C.'s next scheduled match, kickoff time, venue, and live countdown.
